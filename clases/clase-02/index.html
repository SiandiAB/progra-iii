Bytecode

"El idioma universal de Java." Es un código intermedio que ni es fuente ni es máquina. Lo entiende cualquier JVM.

JVM (Java Virtual Machine)

"El traductor que habla con cada sistema operativo." Lee bytecode y lo convierte en instrucciones nativas.

javac = Java Compiler. Convierte .java en .class.

Olvídate del delete (C++ → Java)

Java tiene un robot jardinero que limpia la memoria por ti.

Memoria Stack

Rápida, ordenada (LIFO). Para variables locales y tipos elementales. Se limpia sola al salir del método.

Memoria Heap

Donde viven los objetos. Es dinámica, compartida y más lenta. El GC la monitorea constantemente.

Garbage Collector

Monitorea el Heap y elimina objetos sin referencias. Automático, pero no mágico.

new

Operador que reserva memoria en el Heap para crear un objeto.

Heap

Zona de la RAM donde viven todos los objetos. Es dinámica y compartida.

Memory Leak

Cuando un programa ocupa memoria que nunca libera, volviéndose lento hasta colapsar.

Advertencia: No es perfecto: si guardas referencias innecesarias, el GC no actúa y puedes provocar un Memory Leak.

int vs Integer: Tipos elementales y Wrapper Classes.

int (Tipo Elemental) Integer (Wrapper Class)
Vive en el Stack (Rápido) Vive en el Heap (Objeto)
No puede ser null Puede ser null
Perfecto para matemáticas y contadores Necesario para Colecciones (ArrayList)
int edad = 25; Integer edadObj = 25; (Autoboxing)

Stack

Memoria rápida y ordenada (LIFO) para variables locales y llamadas a métodos.

Wrapper Class

"Envoltura" que convierte un tipo elemental en un objeto.

Objeto

Instancia de una clase, vive en el Heap.

Colecciones

Estructuras dinámicas como ArrayList, HashMap (solo guardan objetos).

Autoboxing

Conversión automática de elemental → Wrapper.

Unboxing

Conversión automática de Wrapper → elemental.

Pertenece a la Clase, NO al Objeto

La palabra clave static

Carro.java 
public class Carro {
    // ATRIBUTO DE INSTANCIA (Cada carro tiene el suyo)
    private String color;

    // ATRIBUTO ESTÁTICO (Pertenece a la CLASE)
    private static int totalCarros = 0;

    public Carro(String color) {
        this.color = color;
        totalCarros++;  // Aumenta el contador GLOBAL
    }

    public static int getTotalCarros() {
        return totalCarros;  // Método de clase
    }
}

Factorial Recursivo: C++ vs C# vs Java

C++ Lenguaje Nativo
factorial.cpp 
#include <iostream>
using namespace std;

int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

int main() {
    int num = 5;
    cout << "Factorial: " << factorial(num) << endl;
    return 0;
}
C# .NET Framework
Program.cs 
using System;

namespace RecursividadEjemplo {
    class Program {
        static int Factorial(int n) {
            if (n <= 1) return 1;
            return n * Factorial(n - 1);
        }
        static void Main(string[] args) {
            int num = 5;
            Console.WriteLine("Factorial: " + Factorial(num));
        }
    }
}
