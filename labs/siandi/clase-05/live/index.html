Laboratorio 5a — Taquilla de Cine

Arquitectura de 3 Capas y Eventos GUI

Programación III — Semana 5: Aplicaciones Dirigidas por Eventos (Práctica Guiada)

IntelliJ GUI Designer Modelo-Vista-Servicio ArrayList ActionListener KeyAdapter & MouseAdapter
Duración estimada: 1 hora  ·  Individual

Introducción

En este laboratorio construiremos una aplicación de escritorio para una taquilla de cine usando Java Swing. Aplicaremos la arquitectura de 3 capas (Modelo, Servicio, Vista) y utilizaremos eventos para manejar las interacciones del usuario: clics en botones, teclado (Enter) y ratón (hover).

Trabajaremos con IntelliJ IDEA y su GUI Designer para crear el formulario visualmente, y aprenderemos a cargar y escalar imágenes dinámicamente desde nuestros recursos.

Objetivo: Al finalizar, serás capaz de:
  • Diseñar una interfaz gráfica usando el GUI Designer de IntelliJ.
  • Implementar la separación de responsabilidades en 3 capas.
  • Manejar eventos de acción (ActionListener), teclado (KeyAdapter) y ratón (MouseAdapter).
  • Validar entradas del usuario con try-catch y JOptionPane.
  • Manipular rutas absolutas del sistema para la carga y redimensionado de imágenes.

Paso 1: Crear el Proyecto y Estructura de Paquetes

1.1 Crear un nuevo proyecto Java en IntelliJ
  1. Abrir IntelliJ IDEA y seleccionar New Project.
  2. Elegir Java con el JDK instalado (versión 11 o superior).
  3. Nombre del proyecto: TaquillaCine.
  4. Crear el proyecto sin código de ejemplo.
1.2 Crear la carpeta src y marcarla como Sources Root
  1. En el panel de proyecto, hacer clic derecho sobre la carpeta raíz del proyecto.
  2. Seleccionar New → Directory y escribir src.
  3. Hacer clic derecho sobre src → Mark Directory as → Sources Root.
1.3 Crear los paquetes modelo, servicio y vista
  1. Hacer clic derecho sobre src → New → Package.
  2. Escribir modelo y presionar Enter.
  3. Repetir para crear servicio y vista.
¡Atención! ¿Carpeta (Directory) o Paquete (Package)?

Esta es la confusión más común. Si estás creando una división dentro de src (que es azul), siempre debes usar New → Package. La opción Directory se usa para carpetas que no contienen código Java.

1.4 Crear la carpeta resources para imágenes
  1. Hacer clic derecho sobre la raíz del proyecto → New → Directory → resources. Aquí sí usamos Directory.
  2. Hacer clic derecho sobre resources → Mark Directory as → Resources Root.
  3. Dentro de resources, crear la carpeta img.
  4. Colocar el logo de cine con el nombre logo.png dentro de img.
1.5 Estructura visual esperada

Al terminar este paso, la estructura de tu proyecto en IntelliJ debería verse exactamente así:

TaquillaCine/ ├── resources/ │ └── img/ │ └── logo.png └── src/ ├── Main.java (Lo crearemos al final) ├── modelo/ │ └── Boleto.java ├── servicio/ │ └── TaquillaService.java └── vista/ ├── FormTaquilla.form └── FormTaquilla.java

package modelo;

Indica que esta clase vive dentro del paquete modelo.

private String sala;

Atributo privado para guardar el nombre de la sala.

private double precio;

Atributo privado para guardar el precio (número con decimales).

public Boleto(String pelicula, String sala, double precio) {

this.sala = sala;

Hace lo mismo con la sala recibida.

this.precio = precio;

Hace lo mismo con el precio recibido.

}

Cierra el constructor.

public String getPelicula() { return pelicula; }

Devuelve el valor de pelicula a quien lo pida.

public String getSala() { return sala; }

Devuelve el valor de sala.

public double getPrecio() { return precio; }

Devuelve el valor de precio.

@Override

Avisa que estamos reemplazando un método que ya existe en la clase padre (Object).

public String toString() {

Método que define cómo se mostrará el boleto cuando se convierta a texto.

return pelicula + " - Sala " + sala + " - ¢" + precio;

Arma el texto final uniendo los tres datos con guiones y el símbolo ¢.

Paso 5: Conectar los Eventos

Dentro del constructor de FormTaquilla, justo debajo del código de la imagen, agregaremos las lógicas de interacción.

5.1 Eventos de los Botones (ActionListener)
btnVender.addActionListener(e -> {

Escucha los clics en el botón Vender. La flecha -> es una expresión lambda.

try {

Intenta ejecutar el código de abajo; si algo falla, salta al catch.

String pelicula = txtPelicula.getText().trim();

Lee el texto de la película y le quita los espacios sobrantes con trim().

String sala = txtSala.getText().trim();

Lee el texto de la sala y le quita los espacios sobrantes.

String precioStr = txtPrecio.getText().trim();

Lee el precio como texto (aún no es número).

if (pelicula.isEmpty() || sala.isEmpty() || precioStr.isEmpty()) {

Si alguno de los 3 campos está vacío, entra aquí. || significa "o".

JOptionPane.showMessageDialog(this, "Todos los campos son obligatorios.", "Error", JOptionPane.WARNING_MESSAGE);

Muestra una ventana emergente de advertencia pidiendo llenar todos los campos.

return;

Sale del método sin vender nada.

}

Cierra el if de validación de campos vacíos.

double precio = Double.parseDouble(precioStr);

Convierte el texto a número decimal. Si escribes letras, esta línea falla.

if (precio <= 0) {

Si el precio es cero o negativo, entra aquí.

JOptionPane.showMessageDialog(this, "El precio debe ser mayor que 0.", "Error", JOptionPane.WARNING_MESSAGE);

Avisa que el precio no es válido.

return;

Sale sin vender.

}

Cierra el if de precio.

Boleto boleto = new Boleto(pelicula, sala, precio);

Crea un nuevo objeto Boleto con los 3 datos.

servicio.venderBoleto(boleto);

Envía el boleto al servicio para guardarlo en la lista.

JOptionPane.showMessageDialog(this, "¡Boleto vendido!\n" + boleto.toString(), "Éxito", JOptionPane.INFORMATION_MESSAGE);

Muestra confirmación con los datos del boleto. \n hace un salto de línea.

lblMensaje.setText("Boletos vendidos: " + servicio.contarBoletos());

Actualiza la etiqueta inferior con el total de boletos vendidos.

} catch (NumberFormatException ex) {

Si parseDouble falló (escribiste letras en el precio), salta aquí.

JOptionPane.showMessageDialog(this, "El precio debe ser un número válido.", "Error de Formato", JOptionPane.ERROR_MESSAGE);

Muestra el error de formato en lugar de que el programa se cierre de golpe.

}

Cierra el catch.

});

Cierra el listener del botón Vender.

btnTotal.addActionListener(e -> {

Escucha los clics en el botón Total.

double total = servicio.calcularTotal();

Pide al servicio la suma de todos los ingresos.

JOptionPane.showMessageDialog(this, "Total de ingresos: ¢" + total, "Resumen", JOptionPane.INFORMATION_MESSAGE);

Muestra el total de ingresos en una ventana emergente.

});

Cierra el listener del botón Total.

btnLimpiar.addActionListener(e -> {

Escucha los clics en el botón Limpiar.

txtPelicula.setText("");

Vacía el campo de película.

txtSala.setText("");

Vacía el campo de sala.

txtPrecio.setText("");

Vacía el campo de precio.

Muestra un mensaje de confirmación.

});

Cierra el listener del botón Limpiar.

txtPrecio.addKeyListener(new KeyAdapter() {

Se ejecuta cada vez que se presiona una tecla.

if (e.getKeyCode() == KeyEvent.VK_ENTER) {

Si la tecla presionada es Enter, entra aquí.

btnVender.doClick();

Dispara el clic del botón Vender automáticamente, como un "clic fantasma".

}

Cierra el if.

}

Cierra el método keyPressed.

});

Cierra el listener de teclado.

btnVender.addMouseListener(new MouseAdapter() {

Agrega un sensor de ratón al botón Vender.

@Override

Avisa que reemplazamos el método mouseEntered.

public void mouseEntered(MouseEvent e) {

Se ejecuta cuando el puntero ENTRA al botón.

btnVender.setBackground(Color.CYAN);
