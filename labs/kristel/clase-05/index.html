Introducción al Reto Individual

En la sesión de hoy construimos en conjunto un sistema robusto aplicando Herencia Polimórfica, Clases e Interfaces Genéricas, Streams, Optional, Lambdas, Switch Expressions y Control de Eventos con GUI Form de Swing.

Ahora deberás demostrar tu autonomía aplicando exactamente los mismos principios arquitectónicos en un nuevo dominio: AeroUNA (Sistema de Control de Vuelos y Reservas de Pasajes). Construirás una solución por capas que gestione vuelos comerciales regulares y vuelos chárter privados, permitiendo la reserva de asientos con control de aforo, validaciones de teclado en tiempo real, búsqueda segura y promociones dinámicas.

No partas de cero: este laboratorio replica exactamente la misma estructura que construiste en el NovaCinema. Tus paquetes y la mayor parte del código son idénticos: solo cambia el dominio y los datos de los métodos. Usa la tabla de equivalencias del siguiente panel.

Objetivos Técnicos Obligatorios:
  • Diseñar una jerarquía de modelo desacoplada utilizando una interfaz genérica (Identificable<K>) y una clase abstracta genérica (ServicioVuelo<K>).
  • Implementar el cálculo polimórfico de tarifas de pasajes mediante Switch Expressions con recargos según el tipo de clase (TipoClase) y uso de Wrapper Classes (Integer, Double).
  • Reutilizar la capa de lógica mediante un servicio genérico (Repositorio<T>) con operaciones de Streams y Optional<T>.
  • Inyectar estrategias de descuento al vuelo utilizando una interfaz funcional (@FunctionalInterface PromocionVuelo) y expresiones Lambda.
  • Construir la vista con GUI Form de IntelliJ, validando entradas numéricas con KeyAdapter (e.consume()), pérdida de foco con FocusAdapter, interactividad con MouseAdapter y cierre seguro con WindowAdapter.

Paso 1: Configurar el Repositorio y Paquetes

1.1 Crear el repositorio en GitHub y clonarlo

Crea en GitHub un repositorio público llamado Laboratorio4-AeroUNA, clónalo en tu computadora con GitHub Desktop y ábrelo en IntelliJ IDEA asegurando la carpeta src como Sources Root.

1.2 Estructura modular de paquetes requerida

Igual que en el livecoding, crea los paquetes directamente dentro de src:

src/ ├── modelo/ // Identificable<K>, ServicioVuelo<K>, VueloComercial, VueloCharter, Enums, PromocionVuelo ├── servicio/ // Filtro<T>, Repositorio<T> ├── vista/ // VentanaVuelos.form, VentanaVuelos.java └── Main.java // Lanzador seguro en Event Dispatch Thread (EDT)

Paso 2: Construir el Modelo Polimórfico y Genérico

2.1 Enums de Categoría y Contratos Funcionales

En el paquete modelo, crea:

  • TipoClase.java: Enum con valores ECONOMICA, EJECUTIVA, PRIMERA_CLASE.
  • TipoCharter.java: Enum con valores TURISMO, EMPRESARIAL, MEDICO.
  • PromocionVuelo.java: Interfaz con anotación @FunctionalInterface y el método Double aplicarDescuento(Double tarifaBase);.
  • Identificable<K>.java: Interfaz genérica con los métodos String getCodigo(), String getDestino(), K getCategoria(), Double calcularPrecio() y String getDetalle().
2.2 Superclase Abstracta Genérica: ServicioVuelo<K>.java
  • Declara public abstract class ServicioVuelo<K> implements Identificable<K>.
  • Atributos protegidos: protected String codigo, protected String destino, protected K categoria, protected Double tarifaBase.
  • Constructor completo para inicializar los atributos y sus respectivos Getters.
2.3 Subclases Concretas: VueloComercial y VueloCharter
  • VueloComercial.java: Hereda de ServicioVuelo<TipoClase>. Contiene Integer capacidadAsientos, Integer asientosOcupados y el getter getAsientosDisponibles() (capacidad − ocupados), igual que FuncionPelicula.
    Implementa public boolean reservarAsientos(int cantidad) que verifique disponibilidad antes de sumar a los ocupados.
    Sobrescribe calcularPrecio() utilizando un Switch Expression:
    double recargo = switch (this.categoria) { case ECONOMICA -> 0.0; case EJECUTIVA -> 25000.0; case PRIMERA_CLASE -> 60000.0; }; return this.tarifaBase + recargo;

    Sobrescribe también getDetalle() para mostrar el vuelo en la consola:
    @Override public String getDetalle() { return String.format("[VUELO COMERCIAL] %s -> %s | Clase: %s | Asientos: %d/%d disponibles | Tarifa: ₡%.2f", codigo, destino, categoria, getAsientosDisponibles(), capacidadAsientos, calcularPrecio()); }

    Ejemplo de salida esperada:

    [VUELO COMERCIAL] AV-101 -> Madrid | Clase: EJECUTIVA | Asientos: 180/200 disponibles | Tarifa: ₡95.000,00
  • VueloCharter.java: Hereda de ServicioVuelo<TipoCharter>. Contiene Integer duracionHoras y Boolean incluyeTripulacionVIP.
    Sobrescribe calcularPrecio() sumando un costo fijo de ₡80,000 si incluye tripulación VIP.
    Sobrescribe también getDetalle():
    @Override public String getDetalle() { return String.format("[VUELO CHÁRTER] %s -> %s | Tipo: %s | Duración: %d horas | Tripulación VIP: %s | Tarifa: ₡%.2f", codigo, destino, categoria, duracionHoras, (incluyeTripulacionVIP ? "Sí" : "No"), calcularPrecio()); }

    Ejemplo de salida esperada:

    [VUELO CHÁRTER] CH-202 -> Isla del Coco | Tipo: MEDICO | Duración: 5 horas | Tripulación VIP: Sí | Tarifa: ₡380.000,00

Paso 3: Capa de Servicio Genérico con Streams y Optional

3.1 Interfaz Funcional y Repositorio Genérico

En el paquete servicio, crea:

  • Filtro<T>.java: Interfaz con anotación @FunctionalInterface y el método boolean test(T item);.
  • Repositorio<T>.java: Clase genérica con:
    • private final List<T> items = new ArrayList<>();
    • public void agregar(T item)
    • public List<T> obtenerTodos() (retorna copia defensiva)
    • public List<T> filtrar(Filtro<T> criterio) usando this.items.stream().filter(criterio::test).collect(Collectors.toList())
    • public Optional<T> buscar(Filtro<T> criterio) usando this.items.stream().filter(criterio::test).findFirst()
    • public List<T> ordenar(Comparator<T> comparador) procesado con Streams.

Paso 4: GUI Form y Control Integral de Eventos

4.1 Formulario con IntelliJ GUI Designer (VentanaVuelos.form)

Diseña un formulario visual en vista.VentanaVuelos (el equivalente a tu VentanaCine) que contenga:

  • Campos de texto: txtCodigo, txtDestino, txtCapacidad, txtTarifaBase.
  • ComboBox tipado: cmbTipoClase (cargado con los valores de TipoClase reutilizando tu método genérico poblarComboEnum del livecoding).
  • Botones de acción: btnRegistrarVuelo, btnReservarAsiento, btnFiltrarPremium, btnBuscarCodigo, btnPromoMillon.
  • Área de salida: txaConsolaVuelos (dentro de un JScrollPane).
4.2 Requisitos Obligatorios de Eventos a Programar:
  1. Validación de Hardware con KeyAdapter y e.consume():
    En txtCapacidad, bloquear la escritura de cualquier carácter que no sea un dígito numérico entero o la tecla de retroceso.
  2. Validación de Foco con FocusAdapter:
    En txtTarifaBase, interceptar focusLost. Si el contenido no puede ser parseado a Double, pintar el fondo de la caja en color rojo/rosado suave (new Color(255, 220, 220)); si es correcto, restablecer a blanco.
  3. Efecto Hover con MouseAdapter:
    En btnRegistrarVuelo, cambiar el cursor a Cursor.HAND_CURSOR al entrar (mouseEntered).
  4. Registro de Vuelo (ActionListener con Lambda):
    Parsear los datos con Wrappers (Integer.parseInt, Double.parseDouble), crear el objeto VueloComercial, guardarlo en el Repositorio<VueloComercial> y actualizar el visor mostrando el getDetalle() de cada vuelo en txaConsolaVuelos (igual que tu método actualizarCartelera del livecoding).
  5. Venta de Boletos y Control de Aforo:
    Al presionar btnReservarAsiento, pedir el código del vuelo mediante JOptionPane.showInputDialog. Buscar el vuelo con repo.buscar(...); si existe, solicitar la cantidad de boletos a comprar y ejecutar vuelo.reservarAsientos(cant) actualizando los asientos disponibles.
  6. Filtrado Declarativo con Streams:
    Al presionar btnFiltrarPremium, mostrar en el área de texto únicamente los vuelos de clase EJECUTIVA o PRIMERA_CLASE.
  7. Búsqueda Segura con Optional<T>:
    Al presionar btnBuscarCodigo, buscar el vuelo y manejar el resultado con .ifPresentOrElse(), mostrando una alerta de éxito o de ausencia de datos.
  8. Estrategia Dinámica con Lambda:
    Al presionar btnPromoMillon, aplicar una promoción del 15% de descuento sobre todos los vuelos usando la interfaz funcional PromocionVuelo (tarifa -> tarifa * 0.85) y listar los precios con rebaja.
  9. Interceptación de Salida con WindowAdapter:
    Configurar setDefaultCloseOperation(DO_NOTHING_ON_CLOSE). En windowClosing, confirmar con JOptionPane.showConfirmDialog antes de liberar los recursos con dispose().

Paso 5: Punto de Entrada Main.java

5.1 Despacho en el Event Dispatch Thread (EDT)

En Main.java (en la raíz de src, sin paquete, igual que el livecoding), configura el Look and Feel del sistema operativo y lanza la ventana dentro de SwingUtilities.invokeLater(() -> { ... }) para garantizar seguridad concurrente en los componentes de Swing.
