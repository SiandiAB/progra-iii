Bytecode

"El idioma universal de Java." Es un código intermedio que ni es fuente ni es máquina. Lo entiende cualquier JVM.

JVM (Java Virtual Machine)

"El traductor que habla con cada sistema operativo." Lee bytecode y lo convierte en instrucciones nativas.

Garbage Collector

Java administra la memoria por ti. Comparémoslo con C++.

C++ Memoria Manual
memoria.cpp 
#include <iostream>
using namespace std;

int main() {
    // Reserva memoria
    int* p = new int(42);
    cout << *p << endl;

    // ¡Obligatorio liberar!
    delete p;
    return 0;
}
Memoria Automática
Memoria.java 
public class Memoria {
    public static void main(String[] args) {
        // Reserva memoria en el Heap
        Integer num = new Integer(42);
        System.out.println(num);

        // ¡No necesitas delete!
        // El GC lo limpia solo.
    }
}
new delete Heap GC Memory Leak

Advertencia: No es perfecto: si guardas referencias innecesarias, el GC no actúa y puedes provocar un Memory Leak.

Tipos Elementales y Wrapper Classes

Java tiene dos mundos: rápidos (Stack) y objetos (Heap).

Tipos Elementales

int double boolean char

Viven en el Stack

Memoria LIFO: el último en entrar es el primero en salir. Rápida y ordenada. Las variables se borran solas al terminar el método.

Wrapper Classes

Integer Double Boolean Character

Viven en el Heap

"Envoltura" que convierte un tipo elemental en objeto. Un objeto es una instancia de clase con atributos y métodos.

¿Para qué necesitamos Wrappers?

1

Colecciones: ArrayList<int> → ArrayList<Integer>
Las colecciones solo guardan objetos, no tipos elementales.

2

Métodos útiles: Integer.parseInt("123")
Convierten texto a número, comparan, etc.

Autoboxing y Unboxing

Integer x = 5; // Autoboxing: int → Integer
Java convierte automáticamente
int y = x; // Unboxing: Integer → int

Cuidado con los bucles: cada autoboxing crea un objeto nuevo en el Heap. Usá int para rendimiento, Integer solo cuando necesités colecciones u objetos.

Pertenece a la Clase, NO al Objeto

La palabra clave static

Carro.java 
public class Carro {
    // ATRIBUTO DE INSTANCIA (Cada carro tiene el suyo)
    private String color;

    // ATRIBUTO ESTÁTICO (Pertenece a la CLASE)
    private static int totalCarros = 0;

    public Carro(String color) {
        this.color = color;
        totalCarros++;  // Aumenta el contador GLOBAL
    }

    public static int getTotalCarros() {
        return totalCarros;  // Método de clase
    }
}

Factorial Recursivo: C++ vs C# vs Java

C++ Lenguaje Nativo
factorial.cpp 
#include <iostream>
using namespace std;

int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

int main() {
    int num = 5;
    cout << "Factorial: " << factorial(num) << endl;
    return 0;
}
C# .NET Framework
Program.cs 
using System;

namespace RecursividadEjemplo {
    class Program {
        static int Factorial(int n) {
            if (n <= 1) return 1;
            return n * Factorial(n - 1);
        }
        static void Main(string[] args) {
            int num = 5;
            Console.WriteLine("Factorial: " + Factorial(num));
        }
    }
}
JVM Platform

Java 21+ Así se escribe hoy (más simple)
Main.java 
public static int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
void main() {
    int num = 5;
    IO.println("Factorial: " + factorial(num));
}

Java 21+ permite omitir public class (clase implícita), usar void main() sin static ni String[] args, e IntelliJ ofrece IO.println() como atajo a System.out.println().

Resumen

C++ vs C# vs Java — Comparativa lado a lado.

Característica C++ C# Java

Funciones sueltas Sí (globales) No (todo en clases) No (todo en clases)

Punto de entrada int main() static void Main() static void main(String[] args)

Laboratorio #1 — Migración de C++ a Java

C++ Código a migrar
main.cpp 
#include <iostream>
#include <string>
#include <vector>

using namespace std;

class Estudiante {
private:
    string nombre;
    int edad;
    double nota;
public:
    Estudiante(string n, int e, double no) {
        this->nombre = n;
        this->edad = e;
        this->nota = no;
    }
    string getNombre() { return nombre; }
    int getEdad() { return edad; }
    double getNota() { return nota; }
};

double calcularPromedio(Estudiante e[], int t) {
    double s = 0;
    for (int i = 0; i < t; i++) s += e[i].getNota();
    return s / t;
}

int main() {
    Estudiante e[3] = {
        Estudiante("Ana", 20, 85.5),
        Estudiante("Carlos", 22, 90.0),
        Estudiante("María", 21, 78.5)
    };
    double p = calcularPromedio(e, 3);
    cout << "El promedio de notas es: " << p << endl;
    return 0;
}
